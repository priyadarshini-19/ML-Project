# Frontend

React + Vite dashboard for the DBSCAN anomaly-detection backend.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

The backend URL defaults to `http://localhost:8000`; override with `VITE_API_URL` in `.env`.
Pages: Home, Upload, Inspection, Preprocessing, DBSCAN setup (Config), Dashboard, Anomaly records, About.
